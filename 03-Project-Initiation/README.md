
# 03 – Project Initiation

The initiation phase established the foundation for the Sauce & Spoon tabletop tablet rollout by defining the project direction, objectives, scope, and key stakeholders.

## Project Documents

### 01. Project Charter

The project charter outlines the business need, project purpose, SMART objectives, scope, key deliverables, estimated budget, assumptions, and project manager responsibilities.

[View Project Charter](Project-Charter.pdf)

### 02. Stakeholder Analysis

The stakeholder analysis identifies the key individuals involved in or affected by the project, evaluates their power and interest, and outlines their roles and engagement requirements.

[View Stakeholder Analysis](Stakeholder-Analysis.pdf)

---

**Key Focus:** Establishing project direction, defining success criteria, and understanding stakeholder expectations.
